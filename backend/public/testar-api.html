Como abrir no MAMP

  1. Copia este ficheiro para backend/public/testar-api.html.
  2. Inicia o Apache e o MySQL no MAMP.
  3. Abre http://127.0.0.1/testar-api.html, usando a porta e o endereço habituais da tua API.
  4. Preenche as duas contas e clica em Executar bateria principal.

Se a tua API usa localhost ou a porta 8888, usa esse mesmo domínio e porta no painel. Abrir o HTML por duplo clique não partilha a origem da API.

Como ler os resultados

  • PASSOU: o código HTTP e as condições indicadas foram verificados.
  • FALHOU: houve uma resposta inesperada ou os dados não correspondem ao esperado.
  • POR TESTAR: uma dependência falhou, a execução parou ou falta uma funcionalidade necessária.

Uma resposta 200, por si só, não valida o fluxo inteiro. O relatório guarda as verificações e os pedidos separados.

Sessão e permissões

Usa contas fictícias. O login devolve o token CSRF; os cookies são enviados pelo navegador. As ações da equipa e do aluno são executadas sequencialmente, com um novo login quando necessário.

A API /api/me não devolve o CSRF no código partilhado. Ao recarregar o painel, volta a entrar para executar escritas.

Um segundo aluno não está configurado. A separação entre dois alunos, concorrência, expiração e falhas reais de infraestrutura não são comprovadas pela bateria principal.

IA e dados de teste

O percurso de reclamação e entrega funciona sem esperar pela IA. Para testar correspondências e notificações, inicia o worker e executa o cenário específico.

O painel usa a API pública e não consegue consultar a fila nem iniciar Python. Os objetos de teste permanecem na base de dados; os IDs ficam disponíveis no relatório.

O reenvio de uma pergunta alterada requer primeiro a alteração pela equipa. As reclamações recusadas continuam bloqueadas.

Se não ligar

Erro de rede / Load failed: verifica se abriste este HTML no mesmo domínio e porta do backend. Confirma o MAMP e o endereço da API. O painel recusa origens diferentes porque o backend partilhado não tem CORS configurado.

404: a rota pode ainda não estar no teu api.php. 500: consulta o log de PHP para verificar o erro. 503: verifica a ligação à base de dados. 403 numa escrita: entra novamente para renovar o CSRF.
